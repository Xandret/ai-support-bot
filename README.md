# Демо-бот: консультант сервиса ремонта на нейросети

Telegram-бот отвечает клиентам своими словами, но **строго по базе знаний компании**: цены, сроки, гарантия, адрес. Если ответа в базе нет, бот не выдумывает, а передаёт вопрос живому менеджеру. Ещё он умеет записывать на диагностику и присылать заявку менеджеру в Telegram.

Демо сделано для вымышленного сервиса «ТехноДок», но под любой бизнес бот перенастраивается заменой текстов в папке `kb/`.

> *EN: Telegram customer-support bot on GigaChat (or any OpenAI-compatible LLM) grounded in a markdown knowledge base, with human handoff, booking flow, rate limiting and offline tests.*

## Что умеет
- **Отвечает по базе знаний.** В папке `kb/` лежат обычные markdown-файлы. Маленькая база целиком уходит в промпт. Большая режется на разделы, и для каждого вопроса выбираются самые подходящие.
- **Не выдумывает цены, и это проверяется кодом.** Каждая сумма в рублях из ответа сверяется с базой. Засчитывается, только если стоит в строке о той же услуге. Так ловится и выдуманная цена, и настоящая, приписанная не той услуге: вживую GigaChat назвал для экрана 3 500 ₽ — цену чистки ноутбука. При ошибке модель получает замечание и переписывает ответ. Если ошибётся снова, клиент получает безопасный ответ без цены.
- **Не выдумывает статус ремонта.** Вопросы вида «где мой телефон» и «готов ли ремонт» перехватываются до нейросети. Бот честно отвечает, что статус знает мастер, и предлагает позвать менеджера.
- **Передаёт менеджеру.** Если ответа в базе нет, клиент видит кнопку «Позвать менеджера», а менеджеру приходят последние сообщения диалога.
- **Записывает на диагностику:** устройство, проблема, удобное время, подтверждение. Заявка приходит в Telegram менеджеру. Нейросеть в записи не участвует, поэтому шаги работают предсказуемо.
- **Держит рамки.** Не уходит в темы не о ремонте и не меняет правила, если его просят «забыть инструкции».
- **Экономит токены.** Не больше 30 сообщений в час на пользователя (настраивается), помнит только последние 6 пар реплик, вопрос обрезается до 1 500 символов.
- **Нейросеть меняется настройкой:** GigaChat или любой OpenAI-совместимый API (YandexGPT, локальная модель) — одна строка в `.env`.

## Как устроено

```
Telegram ─▶ bot/handlers.py   меню, запись (FSM), вызов менеджера
              │
              ▼
          bot/assistant.py    промпт + база знаний + история + лимит + метка передачи
              │                         ▲
              ▼                         │
          bot/llm.py          bot/kb.py  (kb/*.md → разделы → контекст)
          GigaChat | OpenAI-совместимый API
```

Логика консультанта (`assistant.py`) не зависит от Telegram, поэтому тестируется без сети.

## Тесты

```bash
.venv\Scripts\python -m unittest -v
```

36 офлайн-тестов, нейросеть и Telegram не нужны:
- **база знаний:** разбиение на разделы, выбор релевантных;
- **ответы:** очистка Markdown, метки передачи менеджеру и записи;
- **проверка цен:** выдуманная сумма, чужая цена, повтор и безопасный ответ; **перехват вопросов о статусе**;
- **ограничения:** лимит сообщений со скользящим окном, история;
- **сквозные сценарии Telegram** (`tests/test_flow.py`): в диспетчер подаются апдейты, а исходящие запросы перехватываются. Проверены запись от начала до заявки менеджеру, отмена посреди записи, кнопка цен без вызова нейросети, передача менеджеру, падение нейросети, молчание бота в группе заявок и демо-копия заявки.

## Запуск на своём компьютере

1. **Бот в Telegram.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username → скопируйте токен.
2. **Ключ GigaChat.** Зайдите на [developers.sber.ru](https://developers.sber.ru/studio) через Сбер ID → создайте проект **GigaChat API** (для физлиц есть бесплатный лимит) → «Получить ключ» → скопируйте **ключ авторизации**.
3. **Сертификат.** GigaChat работает с сертификатом НУЦ Минцифры. Скачайте «Корневой сертификат» (`russian_trusted_root_ca.cer`) на [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt), положите в папку проекта и укажите путь в `GIGACHAT_CA_BUNDLE`. Файл в git не попадает.
4. **Запуск.** Запустите `run.cmd`. При первом запуске он создаст окружение и файл `.env` и откроет его в блокноте. Впишите `BOT_TOKEN`, `GIGACHAT_CREDENTIALS` и `GIGACHAT_CA_BUNDLE`, сохраните и запустите `run.cmd` ещё раз.
5. **Куда приходят заявки.** Лучше всего в отдельную группу:
   - создайте в Telegram группу, например «Заявки», и добавьте в неё бота;
   - напишите в группе `/myid`, бот ответит числом вида `-100…`;
   - впишите это число в `MANAGER_CHAT_ID` и перезапустите бота.

   В группе бот только присылает уведомления и не отвечает на сообщения, так что туда можно добавить всех менеджеров. Если заявки нужны в личку, напишите `/myid` боту в личке.
6. **Демо-режим.** `DEMO_SHOW_MANAGER_VIEW=true`: после заявки или вызова менеджера клиент видит копию того, что получил менеджер. Это для показа покупателям; в боте для настоящего бизнеса поставьте `false`.

Бот работает, пока запущен `run.cmd`; если упал, перезапускается сам. Для круглосуточной работы есть `Dockerfile`: `docker run -d --restart=always --env-file .env ...` на любом VPS.

## Под другой бизнес
1. Замените файлы в `kb/`: один раздел — один заголовок `##`. Кнопка «Цены» показывает раздел, в названии которого есть «цен».
2. Поменяйте `BUSINESS_NAME` в `.env` и приветствие в `bot/handlers.py`.
3. Прогоните тесты и задайте боту 10–15 типичных вопросов клиентов.
